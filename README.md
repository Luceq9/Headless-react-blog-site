# Headless Blog Theme Starter

A simple blog theme starter built with React, Vite, React Router and Tailwind CSS.

The project is prepared for a headless WordPress workflow. It currently works with mock data, so it can be launched without a WordPress backend. Later, the mock data can be replaced with WordPress REST API responses.

## Features

- React + Vite setup
- React Router routing
- Blog homepage
- Blog listing page
- Single post page by slug
- Category page
- Mock blog posts
- Responsive header and footer
- Search-ready header
- Basic accessibility helpers
- Prepared for WordPress REST API integration

## Routes

```txt
/                         Home page
/blog                     Blog listing
/post/:slug               Single post page
/blog/kategoria/:slug     Category page
